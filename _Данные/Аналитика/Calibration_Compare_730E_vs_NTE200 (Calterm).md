## 1. TIB = Trip Information Base (НЕ «Thermal Imbalance»)

> [!danger] Ключевое исправление
> В реальной калибровке группа называется буквально **`Group: TIB ---- Trip Information Base`**. **TIB = Trip Information Base** — подсистема **учёта рейса/наработки и расхода топлива** (аналог «бортового счётчика рейса»). Прежняя расшифровка *«Thermal Imbalance Balance / Compensation»* — **ошибочна** и снята.

Содержимое группы TIB — **только накопители и счётчики** (read-only телеметрия), которые ничем не управляют:
- `T_TIB_Trip_*` / `T_TIB_Total_*` — накопленные топливо, время работы, наработка, средние нагрузка/обороты/мощность за рейс и за весь срок;
- `T_TIB_*_Derate_Time`, `*_RPM_Derate_Fuel_Used` — учёт времени/топлива на дерейтах;
- `T_TIB_FCR_*` — мониторинг расхода топлива (Fuel Consumption Rate);
- сопроводительный текст: *«This value should really be considered private power-down data»* — это **сохраняемые при выключении статистические данные**, а не команды управления.

## 2. `C_TIB_Fuel_Adjust_Upper_Limit` — НЕ влияет на впрыск

| Параметр | 730E | NTE200 | Ед. | Комментарий из ЭБУ |
|---|---|---|---|---|
| `C_TIB_Fuel_Adjust_Upper_Limit` | **100.000** | **200.000** | % | *«Upper Limit for Fuel Adjustment Factor»* |

Параметр физически расположен **внутри блока TIB → FCR (Fuel Consumption Rate) monitoring**, между `T_TIB_FCR_Volume_Fuel_Used`, `T_TIB_FCR_Mass_Fuel_Used`, `T_TIB_FCR_Engine_Run_Time` и `FCR_Short_Term_Log`.

> [!check] Вердикт
> `C_TIB_Fuel_Adjust_Upper_Limit` (100→200 %) — **верхний предел поправочного коэффициента в подсистеме учёта расхода топлива (FCR)**, а не доза и не полномочия впрыска. Он меняет максимально допустимую поправку при **расчёте/отображении израсходованного топлива** (отчётность, телеметрия), но **НЕ команду форсункам и НЕ цикловую подачу**.
> Признаки: (1) группа Trip Information Base / FCR — это учёт, а не управление; (2) во всём файле **нет параметров управления впрыском рядом с ним** (нет rail pressure, SOI/injection timing, fueling map, injector trim, cylinder balance в дифф-листе); (3) фактическая карта впрыска задаётся **топливным кодом** (`FC0BU52` vs `0WH95`), а не параметром из TIB.
> **Прежний тезис «TIB 200 % → переобогащение → перегрев клапанов» снят как неподтверждённый.**

## 3. Реальные отличия, влияющие на тепловой режим (подтверждены по строкам)

| Параметр | 730E | NTE200 | Ед. | Смысл |
|---|---|---|---|---|
| `C_EPD_OT_RPM_Drt_En` | **1** (вкл) | **0** (выкл) | флаг | 🔴 Дерейт по T масла **отключён** на NTE200 |
| `C_EPD_OT_Spd_Derate` | 2200 | 1675 | RPM | (флаг выкл → не работает) |
| `C_EPD_CT_TB_Time_To_Max_Trq_Drt` | 0 (мгнов.) | **43** | с | Задержка ввода торк-дерейта по ОЖ |
| `C_EPD_CP_TB_Time_To_Max_Trq_Drt` | 0 (мгнов.) | **51** | с | Задержка ввода торк-дерейта по давл. масла |
| `C_EPD_IMT1…4_Spd_Derate` | 1675 | 1666,67 | RPM | Незначительная правка дерейта по T наддува |
| `C_EPD_WIF_RPM_Thd` | 2000 | **0** | RPM | Порог дерейта по воде в топливе обнулён |
| `C_ABS_Max_Acctr_Speed` | 1990 | **2100** | RPM | Выше макс. обороты х.х. при 100 % педали |
| `T_ABS_MaxRef_1` | 1990 | 1970 | RPM | Потолок оборотов в позиции 1 |
| `T_ABS_MaxRef_2/3` | 1990 | **2225,8** | RPM | Выше потолок оборотов в позициях 2/3 |
| `T_ABS_MinRef_1/2/3` | 572 | 715 | RPM | Выше мин. обороты регулятора |
| `C_ABS_DroopMax` | 0 (изохрон.) | **20** | % | Допуск колебаний оборотов ±20 % |
| `C_ABS_Stability_Thd` | 0 | **−2,0** | — | Иной порог индекса стабильности привода |
| `_Fuel_Code_Part_Number` | FC0BU52 | **0WH95** | — | 🔴 **Иной топливный код = иная карта впрыска** (давление рампы, фазы, дымовой ограничитель) |

> [!check] Что реально является носителем механизма
> 1. **Топливный код `0WH95`** (vs `FC0BU52`) — единственный достоверный носитель отличий **впрыска** между платформами (карты давления/фаз/дымового ограничителя зашиты в коде, а не в отдельном «TIB»-параметре).
> 2. **Кластер сниженной тепловой защиты** (отключённый дерейт по T масла, задержки 43/51 с, обнулённый порог WIF) + **повышенные обороты/droop** (2100→2225 vs 1990; droop 20 % vs 0 %) — механизм удержания высокой EGT без сброса нагрузки.
> 3. **TIB исключён** из причинной цепи — это телеметрия учёта, а не управление.
