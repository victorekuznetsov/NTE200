# _Данные/ГЕ — События бортовой системы

Журналы событий из системы диспетчеризации **Горная Евразия** по 47 машинам NTE200 (гар. №43–89) за апрель–июнь 2026 г.

## Структура файла

| Поле        | Описание                                               |
| ----------- | ------------------------------------------------------ |
| Type        | Log+ = начало события / SRst = снятие события          |
| Event #     | Код события (см. таблицу ниже)                         |
| Sub ID      | Подтип события                                         |
| Name        | Наименование события                                   |
| Time        | Метка времени (UTC+10, Магадан)                        |
| Restriction | Тип ограничения (Неограничивающее/Ограничивающее)      |
| truckspd    | Скорость машины в момент события, км/ч                 |
| state       | Состояние привода (Propel / Retard / Test / Null)      |
