# _Данные/Весовая — Данные системы взвешивания БЕЛАЗ

Данные встроенной системы взвешивания БЕЛАЗ (Payload Management System) по 50 машинам за март–июнь 2026 г. Каждая строка = один рейс.

## Структура файла

| Поле            | Описание                                             |
| --------------- | ---------------------------------------------------- |
| Year/Month/Day  | Дата рейса                                           |
| Hour/Min/Sec    | Время загрузки                                       |
| TruckId         | Гар. номер машины                                    |
| OperId          | Код оператора                                        |
| PayloadNumber   | Порядковый номер рейса                               |
| BucketCount     | Количество ковшей при загрузке (4–6)                 |
| **LoadPercentage** | **% от номинальной грузоподъёмности (220 т)**     |
| StaticPayload   | Фактическая масса в условных единицах (~18 ед./т)    |

> **Номинальная грузоподъёмность БЕЛАЗ 7513 (NTE200): 220 т**
> LoadPercentage > 100 = превышение номинала.

## Физический смысл для двигателя

При 134% нагрузки на NTE200 (БЕЛАЗ 7513):
- Фактический груз: ~295 т вместо 220 т (на 75 т больше номинала)
- Двигатель QSK50 работает на повышенной мощности дольше и чаще
- Тепловыделение пропорционально нагрузке → EGT смещается вверх
- Если при номинале EGT ~500°C, то при 134% расчётная EGT ~535–560°C

**Измеренные EGT** из DML NTE#82: цил. 2 = 567°C, цил. 6 = 567°C при лимите 520°C.
