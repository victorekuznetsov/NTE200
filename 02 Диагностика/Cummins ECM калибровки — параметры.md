# Cummins ECM калибровки — параметры

> [!danger] Исправление от 2026-06-26
> По аутентичному экспорту Calterm (см. [[Calibration_Compare_730E_vs_NTE200 (Calterm)]]): **TIB = Trip Information Base** (учёт рейса/расхода), а НЕ «Thermal Imbalance». Параметр `C_TIB_Fuel_Adjust_Upper_Limit` (100→200 %) — предел поправки в **учёте расхода топлива (FCR)**, **не влияет на впрыск**. Прежняя трактовка снята.

## Ключевые параметры сравнения NTE200 vs 730E-DC

| Параметр | NTE200 | 730E-DC | Влияние |
|----------|--------|---------|---------|
| `_Fuel_Code_Part_Number` | **0WH95** | FC0BU52 | 🔴 Иная карта впрыска (давление/фазы/дымовой ограничитель) |
| `C_EPD_OT_RPM_Drt_En` | **0 (выкл)** | 1 (вкл) | 🔴 Дерейт по T масла отключён |
| `C_EPD_CP/CT_TB_Time_To_Max` | **51 / 43 с** | 0 / 0 | Задержки дерейта (масло/ОЖ) |
| `C_ABS_Max_Acctr_Speed` | **2100** | 1990 | Выше обороты (до 2225 в поз. 2/3) |
| `C_ABS_DroopMax` | **20 %** | 0 % | Допуск колебаний оборотов |
| `C_TIB_Fuel_Adjust_Upper_Limit` | 200 % | 100 % | 🟢 Учёт расхода (FCR), **не впрыск** |
| `OPTION_NUM_DO` | 61042 | 6765 | Разные калибровочные профили |

*Всего отличается ~15 параметров калибровки — аутентичный экспорт Calterm 4.7.1 (КАМСС, 25.06.2026).*

## TIB — Trip Information Base (учёт рейса)

TIB — подсистема **учёта наработки/рейса и расхода топлива** (накопители времени, топлива, средних нагрузки/оборотов; FCR-мониторинг). Это **read-only телеметрия**, не контур управления. `C_TIB_Fuel_Adjust_Upper_Limit` — верхний предел поправочного коэффициента **при расчёте израсходованного топлива** (FCR), а не доза/полномочия впрыска. **На впрыск не влияет.**

## Что реально влияет на тепловой режим

Иной **топливный код `0WH95`** (карта впрыска) + кластер **сниженной тепловой защиты** (отключён дерейт по T масла, задержки 51/43 с, обнулён порог WIF) + **повышенные обороты/droop** (2100→2225 vs 1990; 20 % vs 0 %) → хронически высокая EGT без сброса нагрузки. Подробно — [[Calibration_Compare_730E_vs_NTE200 (Calterm)]].
