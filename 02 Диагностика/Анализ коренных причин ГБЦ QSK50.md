## Суть проблемы за 30 секунд

> [!danger] TL;DR — Коренная причина установлена
> **TIB (Thermal Imbalance Compensation) = 200% на NTE200** вместо 100% как на 730E-DC.
> Двойная компенсационная доза → поздний впрыск → EGT до 567°C (лимит 520°C) → выгорание выпускных клапанов.
> **Решение: перекалибровать ЭБУ, снизить TIB до 100%.**

| Параметр | Значение |
|----------|----------|
| Объект | Полюс Магадан (золотодобыча, Магаданская обл.) |
| Техника | БЕЛАЗ-7513 NTE200, 220 т |
| Двигатель | Cummins QSK50 MCRS, V16, 2500 л.с. |
| Система впрыска | MCRS (Modular Common Rail System) |
| Tier | Tier 2 (без DPF, без EGR) |
| Отказы | **30 ремонтных событий, 24+ ед.** |
| Симптом | Выгорание выпускных клапанов |
| Контрольная группа | 730E-DC (тот же двигатель, тот же объект) |
| Отказы 730E-DC | **0** — ключевое |

## Механизм отказа

> [!abstract] Что такое TIB и почему 200% = проблема
> **TIB (Thermal Imbalance Compensation)** — параметр ЭБУ QSK50, который добавляет дополнительную дозу топлива в те цилиндры, где ЭБУ фиксирует пониженную температуру выхлопа (тепловой дисбаланс). Цель — выровнять нагрузку между цилиндрами.
> - При TIB = **100%** компенсирующая доза соответствует расчётной норме Cummins.
> - При TIB = **200%** компенсирующая доза **удвоена**: ЭБУ добавляет вдвое больше топлива.
> - Избыточное топливо не успевает сгореть в такте сжатия → сгорание смещается **ближе к концу рабочего хода** (поздний впрыск по классификации Cummins 378-010).
> - Позднее сгорание: газы дожигаются ближе к открытию выпускных клапанов → **EGT резко растёт**; неполное сгорание топлива при низком давлении → **сажа в масле** (Cummins 378-010, раздел «Late injection consequences»).

## Данные ЭБУ

### Сравнение параметров NTE200 vs 730E-DC

```
DO_Option:          NTE200 = 61042    |  730E = 6765
TIB (Thermal Imb): NTE200 = 200%     |  730E = 100%  ← КРИТИЧНО
Fan Control:        NTE200 = 4        |  730E = 3
Max Speed:          NTE200 = 1900 rpm |  730E = 1900 rpm
```

> [!warning] Параметр DO_Option
> DO_Option = 61042 (NTE200) vs 6765 (730E) — принципиально разные калибровочные профили.
> Возможно, профиль NTE200 не предназначен для карьерного цикла нагрузки.
> **Открытый вопрос:** [[#Вопросы требующие ответа Cummins|→ запрос в Cummins]]

## Северная Евразия — опровержение

### Предложение: перевод CI-4 → CJ-4 (тест 500 м/ч)

> [!danger] Это отвлечение от коренной причины
> 1. Масло **одинаково** на NTE200 и 730E-DC — не дифференцирующий фактор
> 2. Топливо Е5 (≤10 мг/кг) — переход на CJ-4 не требуется даже по Cummins
> 3. CJ-4 создан для DPF — на QSK50 Tier 2 DPF отсутствует — нет преимуществ
> 4. CJ-4 имеет **меньший начальный TBN** — хуже при высоких тепловых нагрузках
> 5. Реальная причина (TIB=200%) останется нетронутой

> [!quote] Cummins 378-003 — контраргумент
> *«Более высокий номер CES не означает лучшее масло»*
