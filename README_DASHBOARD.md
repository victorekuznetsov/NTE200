# ⚙️ QSK50 Predictive Analytics Dashboard

Дашборд предиктивной аналитики двигателей **Cummins QSK50** для автосамосвалов
**NHL NTE200** и **KOMATSU 730E**.

## Возможности

- **9 вкладок**, ~60+ интерактивных графиков (Plotly)
- Загрузка данных **из локальной папки** на ПК
- **Авто-распаковка** архивов `.7z` (Log Files, ECM, GE, Payload)
- Поддержка двух форматов INSITE-логов (английские и русские названия колонок)
- Предиктивный анализ: индекс здоровья ДВС, обнаружение аномалий (Z-score),
  тренды EWMA, линейный прогноз с доверительным интервалом
- Экспорт данных в CSV

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
streamlit run qsk50_dashboard.py
```

Откроется браузер по адресу `http://localhost:8501`.

## Использование

1. В **боковой панели** укажите путь к папке с данными (по умолчанию — папка
   с дашбордом).
2. Положите в эту папку файлы данных или архивы `.7z` — они распакуются
   автоматически при первой загрузке.
3. Нажмите **«🔄 Обновить данные»** после добавления новых файлов.
4. Фильтруйте по самосвалам, экспортируйте таблицы кнопками на вкладках.

### Ожидаемые файлы

- INSITE-логи: `*.csv` (формат INSITE Professional 8.x)
- `Данные с ECM.7z` → `{№}_ECM0_{дата}.xlsx`
- `Данные GE.7z` → `GE_{№}_{дата}.xlsx`
- `Payload NTE200.7z` → `Весовая_{№}_{дата}.xlsx`
- `ОТЧЕТ Полюс Магадан.xlsx`, `ГБЦ ремонты.xlsx`,
  `Доливки Горная Евразия.xlsx`, `speed and production.csv`

## Пороговые значения QSK50

| Параметр | Норма | Внимание | Критично |
|----------|-------|----------|---------|
| T охл. жидкости | 82–95 °C | 95–105 °C | >105 °C |
| Давление масла | 350–700 кПа | 300–350 кПа | <300 кПа |
| T масла | 85–105 °C | 105–115 °C | >115 °C |
| T выхлопа (ср.) | 380–520 °C | 520–560 °C | >560 °C |
| Разбаланс цилиндров | <30 °C | 30–60 °C | >60 °C |
| Давление картера | 0–3 кПа | 3–7 кПа | >7 кПа |
