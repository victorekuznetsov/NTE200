# Реестр проблем

## Известные проблемы

- [[Износ клапанов ГБЦ QSK50]] — приоритет 1, активна

Создать новую: [[_Шаблоны/Проблема|шаблон]]

## Активные

```dataview
TABLE status AS "Статус", priority AS "Приоритет", system AS "Система", found AS "Обнаружена"
FROM "01 Проблемы"
WHERE file.name != "_Индекс" AND status != "закрыта"
SORT priority ASC
```

## Закрытые

```dataview
TABLE closed AS "Закрыта", system AS "Система"
FROM "01 Проблемы"
WHERE file.name != "_Индекс" AND status = "закрыта"
SORT closed DESC
```
