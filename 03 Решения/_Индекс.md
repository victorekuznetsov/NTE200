# Корректирующие действия

Создать новое: [[_Шаблоны/Решение|шаблон]]

## В работе

```dataview
TABLE status AS "Статус", responsible AS "Ответственный", deadline AS "Срок", problem AS "Проблема"
FROM "03 Решения"
WHERE file.name != "_Индекс" AND status != "выполнено"
SORT deadline ASC
```

## Выполненные

```dataview
TABLE completed AS "Дата закрытия", responsible AS "Ответственный"
FROM "03 Решения"
WHERE file.name != "_Индекс" AND status = "выполнено"
SORT completed DESC
```
