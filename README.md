# NTE200

Репозиторий материалов по проекту NTE200.

## Структура

| Папка | Содержимое |
|-------|-----------|
| `техотчеты/` | Технические отчёты по машинам (ТЕХНИЧЕСКИЙ ОТЧЁТ гар№43–92, Тех отчет 47–92) |
| `форсунки/` | Отчёты и тесты форсунок |
| `гбц-клапаны/` | Материалы по ГБЦ, клапанам, цилиндрам (QSK50) |
| `тесты/` | Тесты машин: 16 файлов по №46, тесты №73 (L2/R1) |
| `данные/` | CSV-файлы рейсов (DML), данные ЭБУ (ECM), логи, архивы |
| `топливо-масло/` | Расход топлива, анализ масел, доливки |
| `аналитика/` | Сводные отчёты, дашборд, презентации |
| `медиа/` | Изображения |
