# Дашборд весового контроля NTE200 (политика 10/10/20)

Компактный одностраничный дашборд по загрузке и производительности парка NTE200
по данным бортовых весовых устройств. Файл дашборда:
`05 Отчёты/Аналитические/Дашборд весового контроля NTE200.html` — **автономный**:
открывается локально двойным кликом, работает без интернета, весь код и данные
внутри одного HTML.

## Что умеет дашборд

- **Гистограмма распределения загрузки** с зонами по политике 10/10/20 и кривой
  нормального распределения; номинал **180 т**.
- **Панель политики 10/10/20** (Caterpillar) с индикаторами PASS/FAIL:
  1. средняя загрузка ≤ номинала (180 т);
  2. не более 10% загрузок > 110% номинала (198 т);
  3. ни одной загрузки > 120% (216 т).
- KPI (средняя загрузка, число циклов, перевезено), донат зон, динамика по месяцам,
  производительность, лидеры перегруза.
- **Фильтры** по месяцу и гаражному № самосвала.
- **Загрузка новых данных**: кнопка «Загрузить .xlsx» читает весовые файлы
  `Весовая_*.xlsx` прямо в браузере (SheetJS), дедуплицирует циклы по ключу
  «борт + дата/время + № цикла» и пересчитывает весь дашборд.
- **Сохранение**: «Сохранить» выгружает обработанный набор в JSON; «Открыть JSON»
  загружает его обратно. Активный набор автосохраняется в localStorage браузера.

## Пересборка встроенных данных

Встроенный (демонстрационный) набор — 46 бортов, 157 645 уникальных циклов из
корневых файлов `Весовая_*.xlsx` и архива `_Архивы/Payload NTE200.7z`.

```bash
# 1. распаковать архив плоско в одну папку
7z e "../../_Архивы/Payload NTE200.7z" -o/tmp/arc_flat
# 2. пересобрать embedded_data.json (той же логикой, что и загрузка в браузере)
node build_embedded.js            # ARCHIVE_DIR=/tmp/arc_flat по умолчанию
# 3. собрать дашборд: подставить embedded_data.json, agg.js, xlsx.mini.min.js и app.js
#    вместо плейсхолдеров __EMBEDDED_DATA__ / __AGG_JS__ / __SHEETJS__ / __APP_JS__
#    в dashboard_template.html
```

## Файлы

| Файл | Назначение |
|------|-----------|
| `agg.js` | единая логика агрегации/дедупликации (общая для браузера и сборки) |
| `app.js` | приложение дашборда (расчёт, графики, фильтры, загрузка/сохранение) |
| `dashboard_template.html` | HTML-каркас с плейсхолдерами для инлайна |
| `build_embedded.js` | Node-скрипт пересборки `embedded_data.json` |
| `xlsx.mini.min.js` | SheetJS (парсер .xlsx) для сборки и для инлайна в дашборд |
| `embedded_data.json` | сгенерированный встроенный набор (партиции борт×месяц) |

Номинал 180 т и пороги 10/10/20 заданы в `agg.js` (`NOMINAL`, `P110`, `P120`) и в
`app.js`. При изменении номинала пересоберите `embedded_data.json`.
