Прочитать свежие тестовые PDF-файлы форсунок, извлечь данные замеров, обновить дашборд `dashboard_injectors.html` и аналитический отчёт `Анализ форсунок Cummins NTE200.md`, затем закоммитить и запушить изменения.

## Шаг 1 — Поиск PDF-файлов

Ищи новые тесты в следующем порядке (по первому найденному):
1. **Архив `.7z`** в корне репозитория (`/home/user/NTE200/*.7z`) — извлечь через Python py7zr в `/tmp/injectors/`
2. **PDF-файлы** прямо в корне репозитория (`/home/user/NTE200/*.pdf`)  
3. **Папка** `/tmp/injectors/` — если уже распакована ранее
4. **Любые аргументы** переданные к скиллу (путь к файлу или папке)

Извлечение архива:
```python
import py7zr, glob, os
archives = glob.glob('/home/user/NTE200/*.7z')
for a in archives:
    with py7zr.SevenZipFile(a, 'r') as z:
        z.extractall('/tmp/injectors/')
```

## Шаг 2 — Чтение PDF и извлечение данных

Для каждого найденного PDF-файла читай его через Read tool.

Из каждого PDF извлеки:
- **Машина** (`NTE200 #NN`) — из имени файла или заголовка документа
- **Позиция форсунки** (например `1L`, `3R`, `6R`) — из имени файла или документа
- **Дата теста** — из документа
- **Leak 200**: значение обратки (норма 0–10 см³)
- **Leak 1600**: значение обратки (норма 0–20 см³)
- **P01** (1600 бар, 2150 мкс, 400 об/мин): подача (норма 441,5–495,5 см³), обратка (норма 0–130 см³)
- **P02** (1000 бар, 1450 мкс, 400 об/мин): подача (норма 220–260 см³)
- **P03** (400 бар, 1300 мкс, 1000 об/мин): подача (норма 16–30 см³)
- **P04** (750 бар, 890 мкс, 800 об/мин): подача (норма 41–51 см³)

Стенд: «Поток CR-2 v1.5» (SN:00604), программа GR TESTING.

## Шаг 3 — Проверка прохождения тестов

Нормы:
```
Leak200: обратка 0–10
Leak1600: обратка 0–20
P01: подача 441.5–495.5, обратка 0–130
P02: подача 220–260
P03: подача 16–30
P04: подача 41–51
```

Для каждого параметра определи статус: `ok` / `hi` (превышение) / `lo` (недобор).
Итог форсунки: `ГОДНА` если ВСЕ параметры ok, иначе `БРАК`.

Критичность:
- **КРИТИЧЕСКОЕ** — отклонение >15% от границы нормы хотя бы в одном тесте
- **НЕУДОВЛЕТВОРИТЕЛЬНОЕ** — отклонение 5–15%
- **ПОГРАНИЧНОЕ** — отклонение <5%
- **ГОДНА** — всё в норме
