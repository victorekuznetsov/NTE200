# Анализ коренных причин отказов ГБЦ QSK50 — NTE200

## Обзор расследования

> [!abstract] Суть проблемы
> На парке самосвалов **БЕЛАЗ-7513 NTE200** зафиксированы массовые отказы головок блока цилиндров (ГБЦ) двигателей Cummins QSK50. 30 ремонтных событий на 24+ единицах. Основной симптом — **выгорание выпускных клапанов**. Идентичный парк 730E-DC на том же объекте, с тем же маслом и тем же топливом — **ни одного отказа ГБЦ**.

### Контекст

| Параметр | Значение |
|----------|----------|
| Объект | Полюс Магадан (золотодобыча, Магаданская обл.) |
| Техника | БЕЛАЗ-7513 NTE200, 220 т |
| Двигатель | Cummins QSK50 MCRS, V16, 2500 л.с. |
| Система впрыска | MCRS (Modular Common Rail System) |
| Tier | Tier 2 (без DPF, без EGR) |
| Отказы | 30 ремонтных событий, 24+ ед. |
| Симптом | Выгорание выпускных клапанов |
| Контрольная группа | 730E-DC (тот же двигатель, тот же объект) |
| Отказы 730E-DC | **0** |

---

## Основная гипотеза и доказательная база

> [!danger] Коренная причина
> **TIB (Thermal Imbalance Compensation) = 200% на NTE200** против 100% на 730E-DC.
> TIB = компенсационная доза топлива при тепловом дисбалансе.
> Двойная доза = поздний дополнительный впрыск = повышенная EGT = выгорание клапанов.

### Матрица доказательств

| # | Доказательство | Источник | Вес |
|---|---------------|---------|-----|
| 1 | TIB=200% на NTE200 vs 100% на 730E | Данные ECM | 🔴 Ключевое |
| 2 | EGT Cyl2=567°C, Cyl6=567°C (лимит 520°C) | DML NTE#82 | 🔴 Ключевое |
| 3 | 15 параметров калибровки ЭБУ отличаются | ECM сравнение | 🟠 Важное |
| 4 | Сажа от позднего впрыска → износ клапанов | Cummins 378-010 | 🟠 Важное |
| 5 | 730E-DC: 0 отказов ГБЦ (контроль) | Данные парка | 🔴 Ключевое |
| 6 | NTE#83 отказ при 2776 м/ч (новый!) | Тех.отчёт | 🟠 Важное |
| 7 | Сера в топливе ≤6,2 мг/кг (не причина) | Паспорта топлива | 🟢 Исключает |
| 8 | CI-4 — правильное масло для QSK50 без DPF | Cummins 378-005 | 🟢 Подтверждает |

## Технические данные двигателя

### Параметры ECM — сравнение NTE200 vs 730E-DC

```
DO_Option:          NTE200 = 61042    |  730E = 6765
TIB (Thermal Imb): NTE200 = 200%     |  730E = 100%  ← КРИТИЧНО
Fan Control:        NTE200 = 4        |  730E = 3
Max Speed:          NTE200 = 1900 rpm |  730E = 1900 rpm
```

> [!warning] Параметр DO_Option
> DO_Option определяет конфигурацию приложения двигателя. Значение 61042 (NTE200) vs 6765 (730E) означает принципиально разные калибровочные профили — возможно, профиль NTE200 не предназначен для данного типа нагрузочного цикла карьерного самосвала.

### Температуры выхлопных газов (DML NTE#82)

| Цилиндр | EGT °C | Норма | Статус |
|---------|--------|-------|--------|
| Cyl1 | ~480 | ≤520 | ✅ |
| Cyl2 | **567** | ≤520 | ❌ +47°C |
| Cyl6 | **567** | ≤520 | ❌ +47°C |
| Cyl11 | ~98 | — | ⚠️ Датчик неисправен |
| Остальные | 450–510 | ≤520 | ✅ |

## Анализ масел — CI-4 vs CJ-4

### Официальная позиция Cummins (документ 378-005)

> [!quote] Cummins Bulletin 5407411, раздел 378-005
> *«Там, где содержание серы в топливе выше 15 промилле, и не используется очистка отработавших газов, **не используйте масла стандартов CES 20081, CES 20086, CES 20087** [...] Для такого топлива рекомендуется использовать масла по стандарту **CES 20078**»*

### Таблица допуска масел для QSK50

| Масло | Стандарт | QSK50 без DPF | Ограничение |
|-------|---------|----------------|-------------|
| CI-4 Plus | CES 20078 | ✅ Разрешено | Нет |
| CJ-4 | CES 20081 | ⚠️ Условно | Только при сере <15 ppm |
| CK-4 | CES 20086 | ⚠️ Условно | Только при сере <15 ppm |

### Почему CJ-4 не решает проблему

```
CJ-4 создан в 2007 году для совместимости с DPF (сажевый фильтр)
QSK50 Tier 2 → БЕЗ DPF → переход на CJ-4 не даёт преимуществ
CJ-4 имеет МЕНЬШЕЕ начальное TBN → хуже нейтрализует кислоты
Предложение Горной Евразии = отвлечение от реальной причины (TIB=200%)
```

> [!info] Ключевой аргумент из Cummins 378-003
> *«Более высокий номер CES не означает лучшее масло»*

## Анализ документов Cummins (Bulletin 5407411)

### 13 разделов руководства по маслам

#### 378-001 — Введение
- Нарушение процедур = потеря гарантии
- Применять совместно с Owner's Manual (Procedure 018-003)

#### 378-002 — Назначение масла
- 7 функций: смазка, охлаждение, очистка, антикоррозия, антиокисление, уплотнение, **гидравлика**
- Критично: масло = рабочая жидкость гидропривода MCRS-форсунок QSK50

#### 378-003 — Классификация
```
CES 20078 → CI-4 Plus → базовый стандарт для QSK50
CES 20081 → CJ-4    → создан 2007 г. ТОЛЬКО для DPF/EPA 2007
CES 20086 → CK-4    → создан 2016 г. ТОЛЬКО для DPF/EPA 2017
```

#### 378-004 — Подбор масла
- Правильный CES — из Owner's Manual, Procedure 018-003
- Для QSK50 = **CES 20078**

#### 378-005 — Требования дизель ⭐
- **QSK50 без DPF/EGR** → CES 20078 разрешено безусловно
- CES 20081 — только при сере <15 ppm
- При сере >15 ppm без DPF → **CJ-4 ЗАПРЕЩЁН**

#### 378-007 — Вязкость ⭐
- **QSK50 выше -20°C → обязательно 15W-40**
- Ниже -20°C → 0W-40 / 5W-40 / 10W-40
- 20W-40 и 20W-50 **запрещены** для QSK

#### 378-010 — Загрязнение масла ⭐ КЛЮЧЕВОЙ

> [!quote] Cummins 378-010 — прямое подтверждение механизма отказа
> *«Сажа образуется при **позднем впрыске** и/или **плохой работе форсунок** [...] Она приводит к **ускоренному износу клапанов**, механизмов форсунок и цилиндров с гильзами»*

**TIB=200% = поздний компенсационный впрыск → сажа в масле → износ клапанов**
Этот механизм описан самим Cummins.

#### 378-013 — Контрольные пределы масла

| Параметр | Критическое значение | Действие |
|----------|---------------------|---------|
| Вязкость (100°C) | 12.5–16.3 cSt | Вне диапазона → замена |
| Сажа | ≤5% | Выше → проверить форсунки |
| TBN | ≥2.5 мг КОН/г | Ниже → замена немедленно |
| Разбавление топливом | ≤5% | Выше → диагностика |
| Вода | <0.1% | Выше → проверить ОЖ |

## Предложение Горной Евразии (анализ)

### Программа испытаний масла CI-4 → CJ-4

**Суть:** Горная Евразия предлагает перевести 2 ед. NTE200 на масло CJ-4 и провести испытания 500 м/ч.

**Оценка:**

> [!danger] Это отвлечение от коренной причины
> 1. Масло одинаково на NTE200 и 730E-DC → не является дифференцирующим фактором
> 2. Топливо К5 (≤10 мг/кг) → переход на CJ-4 не требуется даже по Cummins
> 3. CJ-4 создан для DPF, которого нет на QSK50 → нет никаких преимуществ
> 4. CJ-4 имеет меньший начальный TBN → хуже при высоких тепловых нагрузках
> 5. Реальная причина — TIB=200% в ЭБУ — остаётся нетронутой

**Контраргумент Cummins 378-003:**
*«Более высокий номер CES не означает лучшее масло»*
