# QSK50 MCRS — техническое описание

## Основные параметры

| Параметр | Значение |
|----------|----------|
| Модель | Cummins QSK50 |
| Конфигурация | V16, 4-тактный |
| Объём | 50 л |
| Мощность | 2500 л.с. (1865 кВт) |
| Система впрыска | MCRS (Modular Common Rail System) |
| Emission Tier | Tier 2 (без DPF, без EGR) |
| Применение | БЕЛАЗ-7513 NTE200, 730E-DC |

## Система MCRS

- Модульная топливная рейка высокого давления
- Управляется ЭБУ (ECM); карта впрыска (давление рампы, фазы, дымовой ограничитель) задаётся **топливным кодом** (`_Fuel_Code_Part_Number`: FC0BU52 у 730E, 0WH95 у NTE200)
- **TIB (Trip Information Base)** — подсистема **учёта рейса/наработки и расхода топлива** (телеметрия), а НЕ управление впрыском. Параметр `C_TIB_Fuel_Adjust_Upper_Limit` относится к учёту расхода (FCR) и на впрыск не влияет. См. [[Calibration_Compare_730E_vs_NTE200 (Calterm)]]
